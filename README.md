# front-prueba-nunegal

Aplicación frontend desarrollada con Vue 3.

## Tecnologías utilizadas

- Vue 3
- Vite
- Vue Router
- Pinia
- ESLint 9
- Prettier
- Vitest

## Requisitos previos

- Node.js 18 o superior
- npm 9 o superior

## Instalación del proyecto

1. Situarse en la raíz del proyecto sin comprimir
2. Instalar las dependencias del proyecto mediante el comando:
   npm i
3. Iniciar el proyecto
   npm run dev

## Compilación para producción

1. Ejecutar el comando:
   npm run build

## Ejecutar tests

1. Ejecutar el comando:
   npm run test

## Ejecutar lint:

    npm run lint
